# KaiOS Keyboard

Experimenting with input method for KaiOS, because typing on the T9 keyboard fucking sucks! But it doesn't have to.

Current idea is that 1-9 are active keys, with * and # being used to flip through layers. One press either way gets you to more letters, two presses gets you to symbols. Means occaisionally letters will require two presses to appear, but you don't have to wait for any annoying fucking delay to type the same letter twice!
